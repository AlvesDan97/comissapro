## Roteiro rápido de entrevista (15 min) — se a pessoa topou conversar

---

## Como analisar as respostas (para você)

| Se a maioria disser… | Priorize no produto |
|----------------------|---------------------|
| Extrato não bate | Conciliação + radar de divergência |
| Várias lojas / regras | Multilojas + motores de regra + snapshot |
| “Não sei quanto vou receber” | Dashboard + recebíveis + alertas |
| Split frequente | Acordo digital + papéis |
| Só celular / campo | Mobile-first + offline |
| Faixas/metas | Escada + simulador “próximo salto” |
| Imposto/reserva | Alisamento + exportação contador |

**Regra prática:** funcionalidade que aparecer em **dor (Q5)** + **não pode faltar (Q24)** + **disposição a pagar (Q23)** sobe para o topo do backlog.
